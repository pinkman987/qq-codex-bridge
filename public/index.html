聊天模型

填写服务商的 OpenAI 兼容地址，程序调用 /chat/completions。本机模型可用 http://127.0.0.1:端口/v1。

尚未保存
保存在本机配置中，不会回显。已保存时留空保留；更换服务商须重新填写。

使用后，聊天内容会发送到你填写的服务，费用由该 API Key 所属账户承担。

Omni 与语音接口

默认关闭。填好地址、模型和密钥再开启；回复为文字。

Omni 开启后，闲聊文字、图片、语音和主动聊天统一使用下方模型与密钥；上方聊天模型暂不参与闲聊，工作任务继续用 Codex。语音直接理解，不先转写。填写百炼对应业务空间和地域的 Chat Completions 基础地址。

语音转写需支持 /audio/transcriptions。

尚未保存语音密钥
独立保存，不回显，也不自动复用聊天密钥。更换服务商需重新填写。

需要 OneBot 支持 get_record 及 WAV/MP3 转换。语音转写：单文件最多20 MiB、识别请求最多30秒。费用由下方密钥所属账户承担。
