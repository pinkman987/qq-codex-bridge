# 功能与边界
更新日期：2026-10-16。操作步骤以 [使用说明](USAGE.md) 为准；v0.2.0-beta.2 Release ZIP 已包含本轮改动。

## 连接与模型

- SnowLuma 负责 QQ 登录和 OneBot v11 消息连接，本项目负责模型、人设、记忆与工作任务。两个程序均需运行。
- Codex 登录账户可聊天和工作；第三方 API 负责聊天，支持 OpenAI Chat Completions 与 Anthropic Messages。
- 供应商可分别命名、启用，保存独立密钥和多个模型。换服务地址需重新填写对应密钥；网页不回显密钥。
- 工作模型留空可使用当前账户默认选择。输入不支持的名称时给出错误提示，不冒充已成功切换。
- 语音/Omni 新配置入口暂时移除，后台保留旧配置和密钥兼容；已有启用配置仍可能接管闲聊。

## 聊天、人设与记忆

管理员私聊用 `/mode chat` 聊天，群里 @回复；白名单群可开启偶尔主动参与。默认插话概率 8%、最短间隔 3 分钟、每群每小时最多调用 8 次，先积累至少 3 条上下文。判断保持沉默也可能消耗用量。定时主动私聊已从当前运行流程移除。

私聊和群聊各自保留上下文。默认连续输入等待 700 毫秒聚合，最长聚合等待 2 秒；每个会话队列最多 30 条。模型生成中的新闲聊按会话排队，工作任务不合并文件操作指令。

人设从预设库载入编辑；保存预设与保存应用分开。网页试聊可使用已应用设置或页面草稿，选填只读记忆快照，正常消耗模型用量，但不发送 QQ 或写正式会话。每条测试输入最多 4000 字符，历史最多 20 条，过长需清空。

默认近期上下文 15 轮、历史资料预算 6000 字符，可分别设置为 1–30 轮、2000–20000 字符。较旧资料最多保留 16 条来源摘录。自动记忆最多 80 条，手动内容不被自动覆盖；删除/修改会阻止同一原文再次自动学习。最多 40 条待续话题，可手动结束、重开或删除；新增后显示在按钮下方。历史预算是字符数，不等于 token。

管理员可用 `/梗 词语 | 释义` 保存本会话用语，通过记忆页编辑或删除。群消息、历史记录和用户名都是背景数据，不能授权本地操作。

## 搜索、图片与回复

Codex 闲聊按开关开放托管搜索，不开放命令、文件、MCP 等本地工作工具。部分兼容服务可用原生搜索；不支持的组合会提示。普通群聊插话不搜索。统计以实际工具事件或接口数据为准，不把模型自述当作搜索证据。

图片追问只保留同会话、同发送者最近两张图的内存缓存，最长 10 分钟，有限条目和总字节数；新图替换旧图，重置/重启会清除。不会根据人脸确认真实身份，也不是通用以图搜图。

QQ 默认回复约 120–220 字、4–6 条短内容；这属于生成指引，明确索要细节时可展开。发送前把表格转为逐项文字、清理标题和装饰标记；代码与必要内容保留。仅本轮明确索要链接或追问来源时保留网页链接。没有可核对资料时不编造来源。缺少关键条件先问用户。

讲题仍支持 `/讲题`、`/ti`，退出用 `/退出讲题`、`/unti`；图片需要视觉接口。回复以当前步骤为主。普通聊天无权执行工作任务。

## 工作任务与权限

管理员私聊 `/mode work` 后下达任务。工作目录可在首页选取，或用 `/projects`、`/project 项目名`。有任务、排队消息或待审批时禁止换目录。

任务中心显示要求、进度、文件与结果，支持停止/补充；QQ 使用 `/补充 内容`、`/stop`。停止不撤销已发生的文件改动。文件列表只涵盖引擎已确认的文件编辑，命令产生的改动可能未列出。

开始和关键阶段简短汇报，阶段去重、最短 15 秒间隔、每任务最多 6 条。只在成功返回结果后读一次账户剩余额度并显示刷新倒计时，其他状态不附用量。读取失败显示未知；共享账户额度不是单任务预算。

仅管理员可处理审批。`/approve 编号` 和 `/deny 编号` 针对单次请求，5 分钟不回应自动拒绝。只有一条待答澄清时普通私聊即可回答；多个请求并存使用 `/answer 编号 回答`。普通回复不能批准命令或文件操作。

任务最多 100 条，每条 80 条动态、200 个文件路径和 12000 字符结果；QQ 长结果可到任务中心查看。重启将未完成记录标为中断，不自动执行。QQ 发送失败只记录投递问题，不把已完成工作改为失败。

## 风格学习与数据

学习聊天风格支持粘贴、文件/文件夹、SnowLuma 消息库及 Windows 截图 OCR。导入后先检查校对，再确认发给模型；结果可编辑后加入人设。没有 2000 条记录上限，仍受 64 MiB 请求、图片像素和 30 分钟分析时限等边界约束。

只有管理员本轮明确提出发群请求，结构化建议才可经白名单验证转发。旧 `[发群]` 文本、引用或群成员请求不会触发转发。配置、控制页令牌、会话、记忆和消息库保存在本机，禁止公开上传。

调用统计记录次数、耗时、失败、服务提供的 token，不保存提示词或密钥。账户剩余额度与单次 token 消耗是不同指标；数据缺失显示未知。

当前验证以隔离模型/QQ 测试为主。真实服务质量、跨电脑安装及 Windows 文件夹选择器仍须按 [发布验收](RELEASE.md) 检查。
