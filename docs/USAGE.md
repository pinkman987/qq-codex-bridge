# EchoMate 使用说明
更新日期：2026-10-16。本文对应 GitHub 主分支源码；现有 v0.2.0-beta.1 Release ZIP 未随本次同步更新。

## 两个程序配合使用

SnowLuma 负责登录机器人 QQ、收发消息；EchoMate 连接模型，管理人设、记忆与管理员工作任务。需要让电脑、SnowLuma 和机器人后台保持运行。关闭控制台网页不影响后台；关闭后台则停止服务。

首次启动运行 `npm ci`、`npm start`，或双击 `start.cmd`。在首页按四步教程连接 SnowLuma，再配置模型、管理员 QQ、群白名单及 OneBot v11 正向 WebSocket。连接令牌不是 SnowLuma 网页登录密码。看到「QQ 已连接」后再测试。

## 控制台外观

左上角使用薄荷色小机器人标志。右上角可一键切换浅色/纯黑主题，浏览器会记住选择；页面适配手机宽度。保存操作在桌面顶部、手机底部，未保存草稿有明确提示。

## 日常聊天与人设

管理员私聊发送 `/mode chat` 进入聊天，群里 @机器人提问。聊天可以用已登录 Codex，也可以选第三方供应商。聊天引擎不能执行本地命令；只有管理员工作模式可以处理项目任务。

「聊天风格」先展示人设预设库。「载入编辑」「编辑当前人设」「新建人设」会打开个性设定编辑区。「保存到预设库」只存档；「保存并应用」才更新机器人。取消编辑恢复进入编辑区前的内容。

「聊天测试窗口」上方输入，下方显示结果。可以测试已应用设置或未保存草稿，Ctrl + Enter 发送，也可停止、清空。可选带上管理员私聊记忆，仅只读。测试会正常调用模型、消耗用量，但不发送 QQ、不新增正式聊天记忆。更换测试设置会重新开始试聊。

QQ 答复默认简短，约 120–220 字、4–6 条短内容；明确要求详细方案时才展开。使用纯文本、换行条目，清理 Markdown 表格、标题、强调与装饰线。未索要链接时不发送链接；追问来源时给实际可核对的资料，记录缺失则重新核对，不编造旧来源。缺少关键条件时直接提问，普通细节不反复询问。长度是生成指引，不通过硬截断删掉必要步骤或风险提示。

## 模型供应商

在「聊天模型」选择 Codex，或添加自己的 API 供应商。每个供应商独立保存名称、启用状态、Base URL、API 格式、密钥和模型列表。支持 OpenAI Chat Completions、Anthropic Messages 与旧配置自动识别。选定模型后「保存并应用」。

密钥不回显；留空保留原值，更换服务地址的域名或端口后重新填入对应密钥。连接测试会调用模型。Codex 模型可留空使用当前账户默认选择，不要填写账户不支持的型号。

按需联网搜索取决于选定引擎的能力。Codex 聊天只开放托管搜索，不开放文件、命令等工作工具。普通群聊插话不触发检索。语音/Omni 的界面入口暂时移除；后台保留旧配置兼容，普通保存不会清掉旧密钥或自动关闭已有 Omni 配置。

## 记忆、话题与风格学习

「记忆与话题」按管理员私聊和白名单群分开管理。新增记忆或待续话题后立即在下方显示；可以编辑、删除、结束或重开话题，也能查看保留的近期上下文。聊天轮数和历史字符预算可配置，默认最近 15 轮、历史资料预算 6000 字符。字符数不是 token 数。

管理员可以发送 `/梗 词语 | 释义` 保存自己的用语，仍可在记忆页修改、删除。当前版本没有定时主动私聊功能；群聊「偶尔主动参与」独立设置。

「学习聊天风格」支持 QQ 消息库、粘贴文字、上传文件/文件夹、上传截图。选择来源、导入检查、校对确认，再交给模型分析，编辑结果后加入人设。OCR 在本机处理；确认的聊天记录会发给选定模型。没有 2000 条记录上限，但仍受请求大小、图片像素和分析时限约束。

## 在 QQ 指挥工作

管理员先发送 `/mode work`，再用普通文字描述任务。首页「选择工作目录」可选已配置项目、手动路径或 Windows 文件夹选择器；也可用 `/projects`、`/project 项目名`。有任务、排队消息或待审批时禁止切换目录。

「任务中心」显示任务要求、进度、已报告的改动文件与结果，支持补充要求、停止；QQ 中也可发送 `/补充 内容` 和 `/stop`。停止不会撤销已发生的文件修改。文件清单只包含引擎确认的编辑，命令产生的文件变更可能不在清单内。

QQ 开始和阶段汇报保持简短，阶段提示去重、至少间隔 15 秒、每个任务最多 6 条。账户剩余额度只在工作成功返回结果后显示一次，包括各周期剩余百分比与刷新倒计时。开始、进度、审批、停止和失败不附用量。数据读取失败明确显示未知，账户额度是共享值，不是本任务独占。

缺少信息时，机器人直接问你；只有一条待答澄清时，可直接用普通消息回答。多条问题并存时按提示用 `/answer 编号 回答`。命令/文件审批仍需 `/approve 编号` 或 `/deny 编号`，普通回复不会批准操作，5 分钟未处理自动拒绝。

任务记录最多保留 100 条，每条最多 80 条动态、200 个文件路径及 12000 字符结果。重启时未完成任务记为中断，不自动恢复执行。

## 升级与本机数据

升级前备份 `config.json` 和 `state/`。更新代码后必须停止旧后台再重新启动；仅刷新网页，或再次打开会复用旧进程的启动器，不会加载新的后台代码。前端图标、样式修改刷新页面即可。

配置、密钥、会话、聊天记忆、控制页令牌、消息库和本机备份不得上传。控制页只监听本机，完整登录地址中的令牌不能分享。更多见 [安全说明](../SECURITY.md) 与 [排查指南](TROUBLESHOOTING.md)。

## 当前验证范围

208 项隔离自动测试、58 个脚本及界面/版本检查、模拟启动链路通过。测试使用假 QQ、假模型和假数据。控制台浅深主题、手机布局和主要交互经过隔离页面验证；Windows 文件夹选择器尚未人工点击验收。真实模型回复质量取决于服务和模型，自动测试不代表所有真实账号、模型或电脑已经验收。
