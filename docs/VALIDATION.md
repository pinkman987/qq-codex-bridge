# 0.2.0-beta.1 本机验证

验证日期：2026-10-01。环境：Windows，Node.js 22.13.0 与 24.19.0。

| 项目 | 结果 | 验证边界 |
| --- | --- | --- |
| 自动行为测试 | 两个 Node 版本均 117 项通过，无失败或取消 | 模拟模型、QQ 和本机服务；没有真实模型推理 |
| 模板、语法和界面检查 | 通过 | JSON 校验、脚本语法、重复/缺失元素 ID、版本一致 |
| 全新目录冒烟 | 通过 | 默认暂停、鉴权、API-only 无 Codex 依赖、模型测试、OneBot 登录及管理员私聊往返 |
| ZIP 解压安装 | 通过 | 新目录 npm ci，Node 22.13 冒烟和脚本检查 |
| 前端 | 通过 | 首次打开账号引导、路径错误定位与输入保留、恢复保存、本机检查，无浏览器错误 |
| 响应式布局 | 通过 | 1440px 与 390px 无横向溢出，手机固定保存按钮可见 |
| 发布过滤 | 通过 | 只允许公开文件；真实账号、密钥、控制页令牌、私人本机路径未出现在文本文件中 |
| Git 暂存 | 通过 | 显式公开名单；真实配置、state、依赖、旧私人材料被忽略 |

Node 22 的超时模拟用例需要模拟真实网络的活动句柄，已修正测试的 watchdog；生产请求的超时机制保持不变。

发布复查还补充 4 项测试：结构化内容拒绝识别、普通 400/持续 5xx 有限重试、单条被拒记录定位与最终数量保留、大范围拒绝的调用上限。服务错误不会误报成审核记录被略过。

尚未完成：真实其他电脑上的安装与 QQ/Codex 登录、独立安全审计、上传后的 GitHub CI、非 Windows 真实 QQ 支持。当前结果适合 Windows 本地公开测试版，不构成上述步骤已完成的证明。
